How this run was built

  • The GICS map is unofficial: the Wikipedia list of S&P 500 companies, retrieved for this run. It is not an S&P or MSCI feed. A name that list does not label is excluded from every basket and shown above, not assigned a guessed sector.
  • Invesco’s holdings file labels sectors with names such as Technology, Telecommunications, and Basic Materials. Those are not GICS names, so they are logged and do not get a vote.
  • Sector history is the current holdings book drifted by price. It is not a point-in-time membership history. A company that has left the file is absent from the whole series.
  • Prices are Yahoo Finance adjusted closes, including splits and dividends. They are a personal-machine source, not a license to redistribute.
  • Names added or removed over 15 sessions appear only after a second holdings file has been saved. One file on disk is not treated as turnover.
